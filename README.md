# OrdoVaccins

Aide à la prescription des vaccins : ordonnances prêtes à copier-coller selon l'âge ou la situation du patient, avec le schéma vaccinal et le statut de remboursement (65 %, 100 %, NR).

- Fichier unique `index.html`, sans dépendance : il s'ouvre directement dans un navigateur ou se publie avec GitHub Pages.
- Données : calendrier des vaccinations 2026, avis HAS, mesvaccins.net, ameli.fr (remboursements vérifiés le 22/11/2026).
- Le remboursement est affiché à l'écran (pastilles) mais n'apparaît pas dans le texte copié.
- Les données sont regroupées dans le tableau `DATA` du script, en bas de `index.html`, pour faciliter les mises à jour.

Outil d'aide : il ne remplace ni le calendrier vaccinal officiel ni le RCP des vaccins.
